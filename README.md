# Декоратор логирования

В работе реализован декоратор `log`, предназначенный для логирования выполнения функций.

## Описание

Декоратор логирует имя функции при успешном выполнении.
При возникновении исключения логируется тип ошибки и входные параметры.
Логирование может выполняться в консоль или в файл при передаче аргумента `filename`.

## Тестирование

Для тестирования используется `pytest`.
Вывод в консоль перехватывается с помощью фикстуры `capsys`.
Также проверяется запись логов в файл.

## Запуск тестов и проверка покрытия

```bash
pytest --cov=src --cov-report=term --cov-report=html
