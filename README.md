# Skypro Homework — Module 2, Lesson 12.1  
Работа с финансовыми транзакциями и внешним API

## Описание
В рамках работы реализованы функции для обработки финансовых транзакций и конвертации валют.

Проект включает:
- загрузку данных о транзакциях из JSON-файла;
- получение суммы транзакции в рублях;
- конвертацию валют (USD, EUR → RUB) с использованием внешнего API;
- покрытие функциональности тестами.

## Структура проекта
- `src/utils.py` — функции для работы с транзакциями:
  - загрузка операций из JSON-файла;
  - получение суммы транзакции в рублях.
- `src/external_api.py` — модуль для работы с внешним API курсов валют (Exchange Rates Data API).
- `data/operations.json` — файл с данными о финансовых транзакциях.
- `tests/` — тесты, написанные с использованием `pytest`, `Mock` и `patch`.
- `.env.example` — шаблон файла с переменными окружения.

## Работа с внешним API
Для конвертации валют используется **Exchange Rates Data API**.  
Токен доступа хранится в переменных окружения.

Локально необходимо создать файл `.env` в корне проекта со следующим содержимым:

EXCHANGE_RATES_API_KEY=your_api_key_here


Файл `.env` добавлен в `.gitignore` и не хранится в репозитории.

## Тестирование
Для тестирования используется `pytest`.

- В тестах модуля `utils` внешняя функция конвертации валют мокается.
- В тестах модуля `external_api` мокается HTTP-запрос (`requests.get`).
- Реальные запросы к API при запуске тестов не выполняются.
